Privacy Policy – Havruta

Havruta is an application that allows users to create and participate in personal goal competitions with friends.

Information We Collect

  • Email address (for authentication)
  • Username
  • User-generated content (competitions, progress updates)
  • Device information (for notifications via Firebase)

How We Use Information

  • To create and manage user accounts
  • To enable competitions and progress tracking
  • To send push notifications related to user activity

Data Sharing

We do not sell or share personal data with third parties, except as required to provide the service (e.g., Firebase by Google).

Data Security

We use industry-standard tools and services (Firebase) to store and protect user data.

User Control

Users can stop using the app at any time.
